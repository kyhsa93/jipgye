# tools/render — 렌더 기반 검사

구운 폴더를 **헤드리스 Chrome으로 열어, 브라우저가 실제로 그린 결과**에서 접근성 조건을 잰다.
#274 체인 공통 규칙 1번이 말하는 도구다(#325 = #278 PR A).

## 왜 필요한가

기존 접근성 시험은 `src/css/legacy.css`를 **정규식으로 읽는다**(#276). Tailwind 유틸리티로 그린 요소는
그 파일에 규칙이 없으므로 **#279부터 그 시험은 눈이 먼다.** `tools/golden`의 불변 조건 비교도 parse5로
DOM만 읽어 CSS가 하는 일을 모른다 — `tw:hidden`으로 본문을 통째로 숨겨도 텍스트 다중집합은 그대로다.
CSS가 실제로 무엇을 했는지는 브라우저만 안다.

## 무엇을 재나 (#274 체인 공통 규칙 1번의 ①~⑤)

| 번호 | 검사 | 어떻게 |
|---|---|---|
| ① | 가시 텍스트 | 텍스트 노드마다 `(글자, 상태)`를 뽑아 **375·1280px**에서 기준과 다중집합이 같은지. 상태는 보임/숨김/가림/화면 밖 |
| ② | 가로 넘침 | **320·375px**에서 `documentElement.scrollWidth − innerWidth > 0`. 넘쳤으면 원인 요소까지 |
| ③ | 대화형 요소 크기 | 보이는 대화형 요소의 **높이 44px**(`--tap`)·**폭 24px**(WCAG 2.2 2.5.8 AA). `display:inline`인 글 속 링크는 뺀다 |
| ③ | 입력칸 글자 크기 | `input`·`select`·`textarea`의 계산된 `font-size` **16px** 이상 |
| ③ | 글자 크기 하한 | 보이는 글자의 계산된 `font-size` **12px** 이상(축척 바닥 `--fs-xs` 0.78rem = 12.48px) |
| ③ | 대비 | **네 모드 각각**에서 4.5:1(큰 글자 3:1). 네 모드 = `:root` · `@media (prefers-color-scheme: dark)` · `[data-theme="dark"]` · `[data-theme="light"]` |
| ④ | 건너뛰기 링크 | Tab 한 번 뒤 초점이 `href="#main"`인 링크에 있는지 |
| ⑤ | 영어 모드 | 위를 `localStorage.lang = "en"`을 심은 채 한 번 더 |

## 쓰는 법

```sh
cd tools/render
node bin/check.mjs ../../docs --js both            # 스크립트 끔·켬 둘 다, 장마다 한 줄
node bin/check.mjs ../../docs --pages index.html   # 장을 고른다
node bin/check.mjs 후보 --baseline 기준             # 검사 ①(가시 텍스트)까지 본다
npm test                                            # 고정 fixture 변이 시험 (CI가 돌리는 것)
```

**종료 코드: `0` = 위반 0건 · `1` = 위반 있음 · `2` = 도구가 돌지 못했다.** "안 돌았다"가 "위반이
없다"로 읽히지 않게 `0`과 `2`를 가른다.

## 의존이 0인데 `package.json`이 있는 이유

그 파일의 일이 둘이기 때문이다 — **의존 격리**와 **`npm test`의 실행 단위**. 이 폴더는 앞쪽이 필요
없을 뿐 **뒤쪽이 필요하다**(cto 판정 2026-10-15, #325 결정 1 / #274 체인 공통 규칙 1번).

**도구의 시험을 루트 `test/`에 두지 않는다.** 루트 `npm test`는 CI 말고도 `daily-update`(수집 전)·
`summarize`·`housing-permits`·`official-price` **네 워크플로의 게이트**다. 거기에 헤드리스 Chrome
의존이 섞이면 브라우저가 없거나 흔들리는 날 **수집이 멈춘다** — 국토부·금감원에서 하루치를 다시
받을 방법이 없고 실제로 사흘 연속 유실된 적이 있다(#62). 루트 시험이 브라우저 없이 도는 지금 성질은
우연이 아니라 지켜야 할 것이다.

의존을 실제로 넣게 되면 PR 본문에 **이름·이유·락파일 유무**를 적고 cto 판정을 받는다. 조용히 넣지 않는다.
`package-lock.json`은 의존이 생길 때까지 두지 않는다 — 그래서 CI도 `npm ci` 없이 `npm test`만 부른다.

## CI에 들어가는 것과 아닌 것

| 무엇 | 어디서 | 왜 |
|---|---|---|
| **변이 시험**(`test/`) | **고정 fixture · CI 상시**(`test.yml`의 `render` 잡) | 입력이 안 움직인다 |
| **전수 위반 목록 · 양성 대조** | **PR 때 한 번 · CI 아님** | **실제 `docs/`를 읽는다 — 데일리 커밋이 매일 들어간다** |

가르는 기준은 **비용이 아니라 입력이 매일 바뀌는 것**이다(#8 재발 방지 R3, `tools/golden`의 `test` ↔
`test:live`와 같은 선). 비용으로 적으면 나중에 "기계가 빨라졌으니 넣자"가 나온다.

⚠️ **브라우저를 못 찾으면 건너뛰지 않고 실패한다.** 변이 시험에 env 게이트를 달지 않는다 — 건너뛴
시험은 `ℹ tests`에는 들어가고 `ℹ pass`에는 **0을 보태므로**, 게이트를 달면 "브라우저가 없어서 안
돌았다"가 초록으로 끝난다. `test/COUNT`의 두 수가 같은 것(`33`·`33`)이 그 성질의 자국이다.

## 못 보는 것

- `::before`/`::after`의 `content` 글자 — 텍스트 노드가 아니라 TreeWalker에 안 걸린다(값은
  `tools/golden`의 `data-*` 비교가 본다).
- **배경 이미지·그러데이션 위의 글자 대비** — 픽셀을 읽어야 한다. 위반이 아니라 **「측정 불가」로 따로 센다.**
- 스크롤 위치에 따라 달라지는 겹침(`position: sticky`).
- **영어 모드는 스크립트를 켜야 잰다** — 번역이 페이지 스크립트의 일이라 `--js off`와 `--lang en`은 함께 설 수 없다.

## 같은 폴더의 `bin/style-equal.mjs`는 다른 것이다

소유자가 뺀 **「화면 동일 증빙」 전용 진입점**이고(#276 완료 조건 9 폐기, #247), 이 도구는 그것을
**고치지도 지우지도 않는다**(#325 결정 2). 되살려 뒤 PR의 게이트로 쓰지 않는다 — 소유자가 뺀 자리에
대체 측정을 넣는 것은 결정을 우회하는 것이다. 이어받은 것은 `lib/chrome.mjs`·`lib/serve.mjs` 둘뿐이다.
