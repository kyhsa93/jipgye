# 서울 아파트 구매 의사결정: Phase 0 실행 명세 (초안)

- 관련: #866, #816, #850, #730, #732
- 작성일: 2026-11-10
- 상태: **분석·검증 초안 / 추천 점수 공개 승인 아님**
- 근거: 저장소 `DIRECTION.md` 1부, `README.md`, 각 관련 이슈. 아래 수치·문턱은 검증 전에는 확정하지 않는다.

## 사용자가 풀 문제
1. 보유 현금·총예산·희망 면적·직장 위치로 서울 아파트 매수 후보를 좁힌다.
2. 실거주, 미래가치, 균형의 세 가지 관점으로 **같은 후보 집합**을 설명한다.
3. 왜 포함/제외했는지, 어떤 자료가 부족한지, 신고 지연·취소를 어떻게 처리했는지 확인한다.
4. 방문 뒤 거래가 바뀌었는지 추적하고 후보를 같은 조건으로 비교한다.

## 현재 재사용 가능한 기반 (코드·데이터 구조 확인 필요)
- 국토교통부 서울 25개구 실거래 수집 및 정적 GitHub Pages 배포
- 실거래 검색의 가격·면적·연식·단지명 필터
- 예산대별 매매 비용, 취득세·중개보수, 대출 비용 계산
- 단지 동일 면적 최근 거래 범위 및 공식 지수 시점 보정
- `price-outlook.html`의 오차·기준선 표시 원칙
- `docs/method.html`의 표본/결측 설명
- 실제 연결 여부와 최신성은 각 데이터 파일·빌더·테스트에서 별도 검증한다.

## P0-A. 선행 측정 — 아직 수치 미확인
- GA4/Search Console: 유입 경로, 검색 유입, 결과 페이지 도달률, 재방문을 **집계값만** 확인한다. 접근 권한 없는 수치는 추정하거나 채우지 않는다.
- 개인별 현금, 직장 위치, 관심 단지명은 분석 도구로 전송하지 않는다. 위치 입력은 클라이언트에서 처리하는 방안을 우선 검토한다.
- 10~20명 대상: 예산 조건 입력 → 후보 5개 이해 → 2~3개 비교 → 저장 → 재방문. 과제 성공률, 추천 근거 이해도, 재방문 의향, 실제 재방문을 분리해 기록한다.
- 경쟁 대조: 호갱노노·네이버부동산·리치고·범용 AI에 **동일한 예산·면적·직장 조건**을 적용하고, 출처·표본·제외 이유·지난 결과 재현·오차 공개 여부를 검증한다. 실제 대조 전 우열을 단정하지 않는다.

## P0-B. 후보 및 데이터 규약
1. **예산**: 총매수비용(가격+세금+수수료)과 가용 현금/대출 가정을 구분한다. 대출 승인을 보장하지 않는다. 예산 미달·초과, 자료 부족을 분리 표시한다.
2. **후보 집합**: 서울 아파트, 확인 가능한 단지 식별자, 면적·거래 기간·매매 자료를 기준으로 포함한다. 실거래 신고일과 계약일을 혼동하지 않는다.
3. **동일 단지명**: 이름만으로 단지를 합치지 않고 기존 동일명/식별자 보정 규칙을 재사용한다.
4. **해제/정정**: 취소 및 정정 재신고를 중복 거래로 계산하지 않는다. 거래 표본의 수·기준 기간·최종 수집일을 표시한다.
5. **결측**: 자료 없는 지표를 0점으로 치환하지 않는다. 지표별 유효/결측과 제외 사유를 공개한다.
6. **데이터 충분성**: 문턱은 관측된 결과에 맞춰 사후 조정하지 않는다. 재표집 변동성 및 백테스트를 통해 사전 등록 후 확정한다.

## 3가지 관점: 사용자에게 점수 공개 전 설계
| 관점 | 후보 지표(검증 전) | 보류 조건 |
|---|---|---|
| 실거주 | 지하철 접근성, 생활시설, 단지/면적 적합성, 월 비용 | #850 거리값 검증 실패·시설 출처 불명 |
| 미래가치 | 시점 보정 가격 변화, 거래 표본, 지역 지수, 가격 변동 위험 | 백테스트·기준선 비교 미통과 |
| 균형 | 위 두 관점의 유효 지표 조합 | 어느 한쪽 검증 미통과 |

**현행 DIRECTION.md의 제약:** 미래가치·균형은 명칭과 무관하게 점수/순위를 내지 않는다. 실거주를 포함한 추천 점수·순위·추천 문구의 공개는 소유자 승인 전 금지한다. 승인 전 UI는 조건별 후보 **목록과 근거**만 보여주며, 순위형 TOP 5로 가장하지 않는다.

## 시점 고정 백테스트
- 매월 평가 기준일 T를 고정하고, T 당시 실제로 수집·공개된 자료만 사용한다. 나중에 정정된 자료를 T 시점 입력으로 소급하지 않는다.
- T 시점 후보를 고정해 3/6/12개월 뒤 관측 거래와 비교하되, 거래가 없는 단지는 관측 불가로 분리한다.
- 비교 기준선: 같은 자치구의 단순 기준, 시장 지수, 무작위/단순 필터 후보 등. 상승률 보장·인과 해석 금지.
- 결과: 관측 가능 비율, 제외율, 오차, 신뢰구간, 지역/면적별 편향, 신고 지연 및 생존 편향을 공개한다.
- 문턱은 백테스트 구간 외 데이터로 재평가하며 통과하지 못하면 점수/순위를 보류한다.
