## 즉시 가능한 독립 검증 작업

1. `test/complex-card.test.mjs`의 비교 URL 복원·잘못된 단지 ID 제외·최대 3곳 제한 검사를 확인한다.
2. #730의 명세와 실제 비교 구현 차이만 별도 이슈/PR로 좁힌다. 기존 비교 UI를 새로 만들지 않는다.
3. #732 관련 구현 존재 여부를 코드 검색 후 판단한다. 서버 계정·푸시·이메일 알림은 범위 밖이다.
4. 검색→후보→비교→저장의 클릭 흐름은 GA4 설정을 확인하기 전까지 개인 조건을 이벤트 매개변수에 싣지 않는다.
5. 3모드 추천은 지표 검증과 승인 이전에 **설명용 기획**으로만 남긴다.
