## 4. 비교 계산 (P2)

선택지 둘: **재계약**(요구 보증금, 월세 0 — 확인기와 같은 전세 갱신 범위)과 **이사**(다른 집 한 곳, 전세 또는 월세).
입력: 현재 보증금 P·요구 보증금 A(확인기 칸 재사용 — P는 인상액 표시에만 쓰고 계산에는 안 들어간다), 비교할 집 보증금 D·월세 R, 보증금에 넣을 내 돈 C, 대출금리 r, 예금금리 d, 기간 N개월.

C는 「지금 보증금을 돌려받아 기존 대출을 갚고 남는 돈 + 따로 모은 돈, 새로 빌릴 돈은 빼고」다. 「더 낼 돈」만 넣으면 재계약 대출이 지금 보증금만큼 부풀어 틀리므로 칸 설명에 이 정의를 적고, P가 있으면 「대출 없이 지금 보증금뿐이면 P 넣기」 단추를 둔다.

선택지마다(보증금 S, 월세 M):

- 내 돈 투입 = min(C, S), **계산상 대출(원금)** = S − 내 돈 투입을 보증금의 80%에서 자른 값(`monthlyCost`와 같다). 원금은 비용이 아니다 — 끝나면 보증금으로 갚는다고 본다.
- 월 이자 = 대출 × r ÷ 12, 월 현금 지출 = 월 이자 + M.
- 기간 현금 지출 = 월 현금 지출 × N.
- 기회비용(선택, 기본 켬 — 화면이 켬/끔을 늘 명시해 넘기고 시험이 기본값을 고정한다) = 내 돈 투입 × d ÷ 12 × (1 − 15.4%) × N — 보증금에 묶여 못 받는 세후 예금이자. 내 돈 C가 두 선택지에서 같으므로
  「남는 돈의 이자를 빼는」 전세 vs 월세 화면의 식과 차이가 똑같다. 한 번만 센다.
- 돌려받는 보증금(지금 집 P, 이사 갈 집 S)은 비용에 넣지 않는다.
- 80%까지 빌려도 모자라면(모자란 돈 = 0.8S 를 넘는 몫) 「가정 한도 초과」로 표시하고 어느 쪽이 덜 드는지 말하지 않는다.
  80%는 계산 가정이다 — HF 일반전세자금보증은 보증금 80%·과목별 상한·상환능력 중 적은 금액이고 수도권 단서가 있어 서울의 실제 한도는 더 낮을 수 있다(legal, 2026-10-28 확인). 실제 대출 가능 여부·한도는 판정하지 않는다.
- 금액은 천 원(0.1만원) 단위 정수로 월 항목을 먼저 반올림하고(금리는 bp 정수로 바꿔 분자를 정수로 둔다 — `52.3×24`가 `1255.1999…`가 되는 부동소수 잡음을 막는다), 기간 값은 그 월 값 × N으로 낸다. 판정은 반올림된 기간 합계의 차이로 한다.
- 절대값은 전세 vs 월세 화면(남는 돈의 이자를 빼는 식)과 다르다 — 선택지 사이 **차이**만 같다. 그래서 줄 이름을 「묶인 내 돈의 세후 예금이자」로 달리 붙인다.
- 고정 조건 시나리오다(금리·월세·보증금이 기간 내내 같다). 이사비·중개보수(P5에서 입력), 대출 부대비용·보증료, 세액공제, 관리비,
  보증금 반환 위험, 층·향·동·집 상태 차이는 넣지 않고 「넣지 않은 것」으로 적는다.

결과 문장: 「입력한 조건으로 {N}개월 동안 {재계약이|이사가} {X}만원 덜 듭니다({기준}).」 두 합계를 나란히 두고, 같으면 「같습니다」. 「유리」「적정」「안전」「추천」은 쓰지 않는다.

## 6. 이용 흐름 (P3)

단지·면적 선택(확인기 또는 단지 카드 링크) → 종전·요구 보증금(확인기 칸) → 신규 계약 통계(확인기 답·`check-new`) → **다른 집 조건과 비용 비교**(새 절,
확인기 바로 아래) → 근거·한계(접힌 상자). 같은 장 안이라 다시 입력하지 않는다. 결과 옆 근거 상자에 단지/자치구 기준, 비교 면적,
기간(갱신 24개월·신규 6개월), 비교 거래 수, 금리 관측월, 표본 부족·오래된 자료 여부, 반영하지 못한 차이를 적는다.

## 7. 계측 (P4)

기존 `calculator_result`를 `calculator_type=renewal_move`로 재사용하고(안정된 입력 한 벌당 1회, 서명은 메모리에만), 새 이벤트는 행동이 다른
것만 둔다: `compare_start`(장 하나에 1회, 사용자의 첫 입력), `calculator_unavailable`(사유 `invalid_input`·`cash_short`·`low_sample`),
`evidence_open`(근거 상자를 처음 펼칠 때). 결과 이벤트에 `result_round`(`first`/`repeat`)를 붙여 조건을 바꿔 다시 본 것을 센다.
보내는 값은 정해진 낱말뿐이고, 단지명·주소·금액·금리 입력값·자유 문장은 보내지 않는다. 언어 전환·재렌더는 서명이 같아 다시 보내지 않는다.

## 8. 판정 (pm, 2026-10-28 — 검토 po·data-analyst·engineer·legal)

1. 새 절 id `move`, 자리는 확인기 → 방법 안내(aside) → `move` → `convert`.
