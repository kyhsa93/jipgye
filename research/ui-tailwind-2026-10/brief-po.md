## 3. 시안 방향 세 가지

진단에서 나온 갈림길은 둘이다. **얼마나 바꾸나**(바로잡기만 / 다시 짜기), 그리고 **무엇을 앞세우나**(숫자 / 문장). 세 시안은 이 두 축의 서로 다른 자리다.

| | A 「정돈」 | B 「계기판」 | C 「보고서」 |
|---|---|---|---|
| 한 줄 | 지금 모습에서 어긋난 것만 바로잡는다 | 숫자가 먼저 보이는 조밀한 화면 | 문장이 답이고 표는 근거인 읽는 화면 |
| 푸는 진단 | 1-2·1-4·1-5·1-7 (1-1·1-8은 조금) | 1-3·1-8·1-6 | 1-1·1-2·1-8 |
| 브랜드색 | `#253e81` **유지** | **변경** → 먹색 `#111418` | `#253e81` **유지** |
| 동반 변경 | 없음 | `theme-color`(67장), `manifest.webmanifest`의 `theme_color`, 아이콘(`scripts/build-icons.mjs`의 `BG`, `test/icons.test.mjs`), 워드마크, `scripts/rates-template.html`, `tools/golden` 픽스처 3장 | 없음 |
| 본문 글자 | 16px | 15px(입력칸은 16px 유지) | 17px |
| 밀도 | 지금과 같음 | 높음 | 낮음 |

세 시안 공통: 시스템 글꼴만 쓴다(현행 스택에 `"Noto Sans KR", system-ui`를 뒤에 덧붙이는 정도). **웹폰트는 넣지 않는다** — 외부 요청 또는 자체 호스팅 바이트가 늘고(`index` LCP가 이미 3.7초), 글꼴이 바뀌는 순간 화면이 밀리며, 지금 웹폰트는 0이다. 한글 웹폰트 파일 크기는 재지 않았다(확인 못함). 명조 계열 제목도 쓰지 않는다 — OS마다 기본 한글 명조의 유무가 달라 화면이 갈린다(기기별로 재지 않았다, 확인 못함). 링크색 토큰(`--link`)과 무늬·입력 테두리용 진한 테두리 토큰(`--border-strong`, 바탕 대비 3:1 이상)은 세 시안 모두 새로 둔다.

아래 색 값은 **출발값**이다. 내가 WCAG 식으로 계산해 글자 쌍은 전부 4.5:1 이상, `--border-strong`은 3:1 이상임을 확인했다(스크래치패드 `ui-275-shots/contrast.mjs`). engineer가 값을 고치면 같은 표를 다시 낸다.

### A 「정돈」 — 현행 정돈형

- **색**: 현행 팔레트 유지. 고치는 것 셋 — `--muted`를 `#666` → `#595959`(바탕 대비 5.74 → 7.00), `--link` = 액센트(라이트 `#253e81`, 다크 `#8aa9f0`), `--border-strong` 라이트 `#8a8a8f`·다크 `#6b7080`. 다크의 `--muted`는 `#a6a6a6`.
- **타이포**: 아홉 단을 여섯 단으로 — 13 / 15 / 16 / 20(`h2`) / 24(`h1`) / 28px. 표 칸과 설명 문단을 13.6px → 15px, 13px은 표 머리글과 차트 축에만.
- **간격·밀도**: 4px 배수(4·8·12·16·24·32·48). 반경은 8px와 999px 둘.
- **표·카드**: 구조 그대로. 표 머리글을 회색에서 본문색 600으로, 넓은 화면에서 숫자 열을 내용 폭으로 줄여 표를 왼쪽에 붙인다(최대 56rem). 카드는 회색 바탕 + 테두리 이중을 테두리 하나로. `low-sample`은 지금의 빗금 칸을 `--border-strong`으로 그린다.
- **index 레이아웃 방향**: 순서는 그대로. 머리를 한 줄(워드마크 + 단추 셋)과 갱신 한 줄로 줄이고, 1층 내비를 가로 스크롤 대신 4칸 균등 격자로(넷째가 잘리지 않는다), 넓은 화면에서는 아래 절반을 "AI 요약 | 뉴스" 2단으로 놓아 빈 오른쪽을 채운다.

### B 「계기판」 — 데이터 대시보드형

- **색**: 화면에서 색을 가진 것은 오르내림뿐이다. 브랜드색을 먹색으로 바꿔 "파랑 = 내렸다" 하나만 남긴다(진단 1-6). 라이트 — 바탕 `#f3f4f6`, 카드 `#ffffff`, 글자 `#111418`, 회색 `#555b66`, 테두리 `#d5d9e0`·진한 테두리 `#7b828f`, 액센트 `#111418`·그 위 글자 `#ffffff`·옅은 판 `#e6e8ec`, 오름 `#b42318`, 내림 `#1d4ed8`. 다크 — 바탕 `#0f1115`(현행 유지, manifest `background_color` 불변), 카드 `#181b21`, 글자·액센트 `#e8eaed`, 회색 `#9aa0aa`, 옅은 판 `#1e2229`, 오름 `#ff8a80`, 내림 `#6cb6ff`. 링크는 본문색 + 밑줄.
- **타이포**: 12.5 / 14 / 15 / 18 / 22 / 28px. 값은 크고 굵게(22~28px), 라벨은 12.5px. 작은 글씨가 남는 대신 회색을 줄이고 본문색으로 쓴다.
- **간격·밀도**: 4·8·12·16·24. 반경 6px. 표 행 높이 40px(넓은 화면), 카드 안쪽 여백 12px.
- **표·카드**: 회색 바탕 위 흰 타일. 표는 조밀하게, 옅은 줄무늬, 건수는 값과 같은 줄에. `low-sample`은 칸 전체에 옅은 빗금 바탕을 깔아 빈 칸이 무늬로 읽히게 한다. 머리글 고정(`sticky`)은 시안에서 쓰지 않는다(cmo 확인 대상).
- **index 레이아웃 방향**: 넓은 화면은 12단 — 왼쪽 8단에 추이 카드(이미 값·최고·최저를 가진 카드 넉 장)를 맨 위 2×2로 올리고 그 아래 자치구 표, 오른쪽 4단에 질문 입구·금리와 환율·안내 문단. 맨 아래 전폭에 AI 요약 | 뉴스. 폰은 추이 카드 2열 → 질문 입구 → 표. 새 글자는 만들지 않고 있는 요소의 순서만 바꾼다.
- **이 방향의 제약**: 원칙 5 때문에 `price-outlook`의 전망값은 타일로 키우지 않는다. 질문 입구는 첫 화면에 남긴다(원칙 9).

### C 「보고서」 — 읽기 중심형

- **색**: 브랜드색 유지. 라이트만 종이색으로 — 바탕 `#fcfbf8`, 카드 `#f3f1ea`, 글자 `#1c1b19`, 회색 `#5c5a55`, 테두리 `#dedbd2`·진한 테두리 `#85817a`, 옅은 판 `#e9edf6`, 오름 `#b3261e`, 내림 `#1d4ed8`, 링크 `#253e81`. 다크는 현행 팔레트 그대로에 링크색만 더한다(바탕을 건드리지 않아 manifest 불변).
- **타이포**: 13 / 15 / 17(본문) / 22(`h2`) / 30(`h1`)px, 줄 간격 1.75. 답 문장(리드)은 20px. 표본·기준·단서 설명은 회색 13.6px에서 **본문색 15px**로 올린다. 표 칸 15px.
- **간격·밀도**: 8·16·24·40·64. 반경 4px. 구획 사이를 넓게.
- **표·카드**: 상자를 줄인다. 카드 대신 위아래 괘선과 여백, 단서 문단만 왼쪽 굵은 선의 인용 상자. 표는 가로 괘선만. `low-sample`은 진한 빗금 칸 + 15px 글자.
- **index 레이아웃 방향**: 넓은 화면에서 읽는 단 44rem을 **가운데**에 놓고, 표와 차트 격자만 60rem까지 양옆으로 넓힌다(오른쪽만 비는 것이 아니라 양쪽 여백이 대칭). 질문 입구는 2열 카드 대신 한 줄에 질문 하나씩의 목록, 묶음 제목은 소제목. 안내 문단은 회색 작은 글씨가 아니라 본문 크기의 "읽는 법" 리드.
- **이 방향의 비용**: 글자가 커져 화면이 길어진다. 그리고 "넓은 화면을 쓰자"는 기존 결정(a7bb2fde — "1920px 모니터에서 화면의 40%만 쓰고 나머지는 빈 칸")을 글이 많은 장에서 뒤집는다. 소유자가 C를 고르면 그 결정을 바꾸는 것이다.

### po 잠정 권장과 뒤집히는 조건

권장은 C다. 이유: 1부의 주어가 "숫자가 든 문장과 표본을 밝히는 단서"인데 지금 그것이 가장 작고 흐리며(1-2), `method`는 자산이라 했는데 20,749px 한 줄 글이고(1-2), B는 "시세를 구경하는 사람은 대상이 아니다"와 긴장한다.

시안을 보기 전에 정해 두는 조건 — 하나라도 걸리면 권장을 A로 바꾼다.

### 만드는 것

- **기준**: `8c984329`의 `docs/`(기준선 시트와 같은 SHA라 나란히 놓을 수 있다. main이 움직였어도 이 SHA로 만든다).

- **두 층으로 나눈다.**
  - **1층 — CSS만(DOM 불변)**: 색·글자·간격·반경·표와 카드 생김새·껍데기 폭. HTML·JS는 한 바이트도 바꾸지 않는다. 아래 시트의 전 장에 입힌다.

- **위치**: 저장소 밖 폴더나 로컬 전용 워크트리. **푸시·PR·병합 금지**, 공유 사본(`~/workspace/jipgye`)의 작업 트리와 `docs/`는 건드리지 않는다. 배포 사이트는 바뀌지 않는다.
