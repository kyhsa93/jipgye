# 미래가치 시험 결과 고정 (#816 P1-2)

공개 문구는 `docs/method.html`의 `#future-value-test`와 `#future-value-test-en`이다. 이 폴더는 그 숫자의 입력·기준·스크립트·출력을 고정한다.

이 사이트는 미래가치·균형 점수를 낼 계획이 없다. 이 시험은 점수를 켜는 관문이 아니다. **새 구간이나 새 데이터로 다시 재지 않는다.** 아래 재현은 같은 입력으로 같은 값이 나오는지 확인하는 일이고, 재시험이 아니다.

## 파일

| 파일 | 내용 |
|---|---|
| `PREREG.md`, `PREREG.sha256` | 측정 때 적은 기준 전문과 해시·시각. 한 글자도 고치지 않았다 |
| `common.py`, `m8_future.py`, `m8c_crossfit.py` | 측정 때 돌린 스크립트 그대로 |
| `m8_future.out` | 판정 측정 출력 그대로(S1·S2, 참고 변수 V5·V6 포함) |
| `m8c_crossfit.out` | 결과를 본 뒤의 점검 출력 그대로. 판정을 바꾸지 않는다 |
| `reproduce.sh` | 이 폴더에 새로 쓴 재현 스크립트 |

`PREREG.md`의 코드 이름과 공개 이름: V1 전세가율, V2 거래 수(유동성), V3 앞 구간 변화, V4 가격 경쟁력, B 합성.

## 재현

```bash
SNAP=<빈 디렉터리> bash research/future-value-test-2026-11/reproduce.sh
```

- 입력: 커밋 `cef5ab55435e9d3528d06100bf07387b3464c0a4`의 `raw`·`docs/data`·`scripts`를 `git archive`로 꺼낸다. 작업 트리와 API를 읽지 않는다. 얕은 복제에는 이 커밋이 없을 수 있다.
- 쓰는 원본: `raw/sale`, `raw/rent`, `raw/indicators/rone-districts.json`(R-ONE A_2024_00045), `raw/ecos/apt-price-index.json`.
- 부트스트랩 씨앗은 스크립트에 고정했다(`20261103`). 부동소수 결과가 라이브러리에 따라 달라질 수 있어 버전을 적는다: Python 3.10.12, numpy 2.2.6, pandas 2.3.3, scipy 1.15.3.
- 끝에서 커밋한 `.out`과 바이트 단위로 비교한다.

재현 결과는 맨 아래 「재현 기록」에 있다.

## 기준이 먼저였는가

**기준 파일은 있었다. 그것이 먼저였다는 공개 증거는 없다.**

- `PREREG.md`는 측정 스크립트를 쓰기 전에 적었고 해시와 시각을 남겼다(`PREREG.sha256`, 2026-11-03T01:25:11+09:00).
- 측정 전에 저장소에 커밋하지 않았다. 이 폴더는 결과가 나온 뒤에 커밋한다. 순서의 근거는 파일 시각과 그 파일의 선언뿐이고, git은 파일 시각을 남기지 않는다. 이 저장소의 사전 등록 절차(`scripts/check-prereg-order.ts`)를 통과한 것이 아니므로 공개 문구는 「사전 등록」이라고 쓰지 않는다.
- 기준을 적기 전에 본 값은 `PREREG.md` 첫머리에 있다. 앞 구간 변수와 뒤 구간 변화의 관계를 보지 않았다는 것도 그 파일의 선언이다.

## 기준과 실행의 차이

- 처음 실행은 구 군집 부트스트랩을 등록한 1,000회가 아니라 500회로 돌렸다. 1,000회로 고쳐 다시 돌렸고 당시 기록으로는 판정이 같았다. 첫 실행 출력은 남아 있지 않다. `m8_future.py`의 마지막 수정 시각은 01:41, 지금 출력은 01:43이다.
- `PREREG.md` D절은 항목이 5개라면서 P1 문턱을 0.10/4(97.5%)로 적었다. 0.10/5(98%)로 읽어도 판정은 같다: V2는 둘 다 1.000이고, 나머지는 구 군집 값이 0.373·0.485·0.229·0.721이다.
- `PREREG.md`의 「점수화 근거로 쓰려면 하락·보합 구간 재현이 있어야 한다」는 당시 문장이다. 지금 방침이 아니다. 재현이 있어도 점수를 내지 않고, 재현을 시도하지도 않는다.
